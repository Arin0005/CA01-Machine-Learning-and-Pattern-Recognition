# Breast Cancer Classification — MLPR CA01

This project was developed as part of the **Machine Learning and Pattern Recognition** assessment.

It uses the Breast Cancer Wisconsin dataset to classify tumours as **Malignant (0)** or **Benign (1)** based on 30 numerical features.

## Models Used
- Logistic Regression
- Decision Tree
- K-Nearest Neighbours (KNN)
- Random Forest (Ensemble)

The models were evaluated using accuracy, precision, recall, F1-score and cross-validation. The best-performing model was saved and deployed using Streamlit.

## Live Application

**[Try the Streamlit App](https://ca01-machine-learning-and-pattern-recognition-h2ebjvhwt2p47lkq.streamlit.app/)**

## How to Test

1. Open the application using the link above.
2. Select a ready-made sample to test the model immediately.
3. Alternatively, choose manual input and enter your own values for the 30 features.
4. Click **Predict** to see the classification result.

## Technologies Used

Python, Pandas, Scikit-learn, Joblib and Streamlit.
